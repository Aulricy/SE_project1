## 本轮复现与修复

新增 20 项针对性边界用例，修复前 19 项失败、1 项已有保护；修复后全部通过。

| 问题 | 修复 | 防止回归 |
|---|---|---|
| 商品、预约编号或版本超过数据库整数范围导致异常 | 路径使用有界正整数转换器；版本和预约商品筛选统一有界解析；无效编号 404、版本/筛选 400 | `test_acceptance_edges.py` 的编号、命令目标、版本与筛选用例 |
| 旧审核驳回冲突后，原因清空并换成当前版本 | 回显原原因及原版本，提示显式刷新；商品状态已变化无法继续驳回时仍保留原因文本 | 自动测试及浏览器旧页 409 实测 |
| 卖出记录筛选错误后自动切回买入范围 | 保留合法的原 side、原筛选文字，错误不改变查询意图 | 卖出范围/非法编号用例 |
| 商品写入遇 SQLite 写锁时成为 500 | 三类商品写操作统一把预期锁/约束冲突转为明确 409；先完成回滚和新图片清理 | 独立 SQLite 连接真实持锁，验证创建/编辑/提交及文件清理 |
| 创建图片目录失败未被图片保存错误覆盖 | 把目录创建放入文件保存异常边界，返回字段级 503 并保留文本 | 注入目录 OSError，无新增商品和文件 |
| 超大正文使用默认英文错误页 | 明确的中文 413 页面，业务数据不变 | 缩小请求上限后验证拒绝和原数据 |

本轮没有改变数据库表结构，没有对日常数据库执行迁移或写入测试数据。
